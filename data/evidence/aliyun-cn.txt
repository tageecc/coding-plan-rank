抵扣顺序、重置规则、额度用尽和用量异常排查。
凭证与计费边界
Token Plan 专属 API Key（sk-sp-）：用于 Token Plan 套餐调用，抵扣套餐额度和用量包。
阿里云百炼通用 API Key（sk-）：仅用于抵扣个人版附赠的 Harness 权益额度，不能用于抵扣模型调用额度。
免费额度、资源包、节省计划和账户余额：属于阿里云百炼按量计费体系，与 Token Plan 额度相互独立。
抵扣顺序
优先抵扣当前订阅月的套餐额度；团队版为当前坐席的月度额度。
套餐额度用尽后，个人版自动抵扣用量包额度；团队版从共享用量包抵扣，持有多个共享用量包时优先抵扣最近到期的包。
可用额度用尽后，消耗 Credits 的调用会被阻断，不会自动转为按量计费。可等待下一个订阅月重置、升级套餐或坐席、购买用量包或共享用量包。
Harness 权益不参与上述抵扣顺序。详见Harness 权益。
额度规则
重置与结转
额度按订阅月自动重置，每个订阅月开始时恢复为对应档位的满月额度。重置时间取决于订阅日期，不是每月 1 日。
订阅月内未用完的额度不结转至下一周期。

限流阈值（TPM/RPM）是多少？能否提升？
限流阈值会根据整体负载动态调整，以保障服务稳定性。套餐限流额度不支持提升。遇到限流时可精简上下文、降低任务复杂度，等待约 1 分钟后重试。
