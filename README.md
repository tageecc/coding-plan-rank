## 更新与纠错

GitHub Actions 每天抓取官方资料、验证价格和额度、统计投票，再生成本文。解析失败会标记待核验并保留旧值；数据变化可在提交记录中追溯。

[提交纠错](https://github.com/tageecc/coding-plan-rank/issues/new?template=data-correction.yml) · [自动更新状态](https://github.com/tageecc/coding-plan-rank/actions/workflows/update.yml) · [如何贡献](CONTRIBUTING.md)

结构参考 [awesome-coding-plan](https://github.com/mahonzhan/awesome-coding-plan) 的比较需求；本项目独立核对官方资料，不复用其测试结果。代码与原创整理采用 [MIT](LICENSE)。
