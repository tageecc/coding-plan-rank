Quota and Limits
Quota rules differ between new and existing members:
New members: the weekly quota limit is removed — quota no longer refreshes every 7 days. The rolling 5-hour rate window still applies: too many requests in a short time trigger rate limiting, which recovers automatically once the window rolls over.
Existing members on legacy plans: rules are unchanged — quota refreshes automatically every 7 days from your subscription date, unused quota does not roll over, and the same 5-hour rolling rate window applies.
Both groups share the Kimi membership monthly total quota: if the monthly total is reached, Kimi Code quota is frozen until the monthly quota resets or you upgrade. Monthly usage can be viewed on the Subscription page.
All logged-in devices and API Keys share the same quota; devices inactive for over 30 days are automatically unbound and can be restored by running /login again. Log in to the Kimi Code Console at any time to check remaining quota and rate-limit status and to manage API Keys and devices.
